## How to actually run the deep-check (pick one)
### Option A — temporary admin-only diagnostic endpoint (recommended; E1 applies, then redeploy)
Add to `backend/routers/playbilling.py`, deploy, hit it once as admin, then remove it:

```python
@router.get("/authcheck")
async def play_auth_deepcheck(_: dict[str, Any] = Depends(_verify_admin)) -> dict[str, Any]:
    import json as _json
    raw = (os.environ.get("GOOGLE_PLAY_SERVICE_ACCOUNT_JSON") or "").strip()
    info = _json.loads(raw) if raw.startswith("{") else _json.load(open(raw))
    client_email = info.get("client_email")
    creds = _load_credentials()
    creds.refresh(GoogleAuthRequest())
    pkg = _package_name()
    paths = [
        f"/applications/{pkg}/purchases/subscriptionsv2/tokens/dummy-token-authcheck",
        f"/applications/{pkg}/purchases/products/keys_to_the_universe/tokens/dummy-token-authcheck",
        f"/applications/{pkg}/inappproducts?maxResults=1",
        f"/applications/{pkg}/subscriptions?pageSize=1",
    ]
    results = []
    async with httpx.AsyncClient(timeout=20) as client:
        for p in paths:
            r = await client.get(f"{API_BASE}{p}", headers={"Authorization": f"Bearer {creds.token}"})
            results.append({"path": p, "status": r.status_code, "body": r.text[:200]})
    return {"client_email": client_email, "package": pkg, "results": results}
```
Interpretation: on results[0]/[1], **400/404 = AUTHORIZED** for purchase verification (dummy token → "not found" is the success signal); **401/403 = NOT authorized**. results[2]/[3] test app-info/financial visibility.
