# Submission Forms Cheatsheet

## Apple App Store Connect

### App Information
- [ ] App Name
- [ ] Subtitle
- [ ] Primary Category
- [ ] Secondary Category (optional)
- [ ] Age Rating
- [ ] Privacy Policy URL

### App Privacy
- [ ] Data collection declared accurately
- [ ] Tracking disclosure (if any)

### Pricing & Availability
- [ ] Territories selected
- [ ] Pricing tier selected

### Version Information
- [ ] What's New text
- [ ] Description
- [ ] Keywords
- [ ] Promotional Text
- [ ] Support URL
- [ ] Marketing URL (optional)

### Assets
- [ ] 1024x1024 icon
- [ ] iPhone screenshots
- [ ] iPad screenshots (if applicable)

### Review Information
- [ ] Contact name/email/phone
- [ ] Review notes pasted
- [ ] Demo flow instructions included

---

## Google Play Console

### Main Store Listing
- [ ] App Name
- [ ] Short Description
- [ ] Full Description
- [ ] App Icon (512x512)
- [ ] Feature Graphic (1024x500)
- [ ] Phone screenshots
- [ ] Tablet screenshots (recommended)

### App Content
- [ ] Privacy Policy URL
- [ ] Data Safety form completed
- [ ] Content Rating questionnaire completed
- [ ] Target audience completed

### Pricing & Distribution
- [ ] Free/Paid selected
- [ ] Countries/regions selected

### App Releases
- [ ] Release notes added
- [ ] Internal/closed/open testing completed (if needed)
- [ ] Production release submitted
